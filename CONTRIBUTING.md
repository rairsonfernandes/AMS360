# Guia de Contribuição

Obrigado por considerar contribuir com o **AMS360**! Este documento fornece diretrizes para contribuir com o projeto.

## 📋 Como Contribuir

### 1. Reportar Bugs

Se encontrar um bug, abra uma Issue com:

- **Título claro e descritivo**
- **Passos para reproduzir**
- **Comportamento esperado vs. real**
- **Screenshots (se aplicável)**
- **Ambiente (SO, .NET version, etc.)**

### 2. Sugerir Melhorias

Para sugestões, abra uma Issue com:

- **Título claro**
- **Descrição detalhada da melhoria**
- **Benefícios esperados**
- **Possíveis impactos**

### 3. Enviar Pull Requests

1. Fork o projeto
2. Crie uma branch: `git checkout -b feature/nova-feature`
3. Faça suas alterações
4. Teste localmente
5. Commit: `git commit -m 'Adiciona nova feature'`
6. Push: `git push origin feature/nova-feature`
7. Abra um Pull Request

## 📝 Padrões de Código

### C#
- Use **C# 12** com recursos modernos
- Siga as **convenções de nomenclatura** do C#
- Adicione **comentários XML** para métodos públicos
- Escreva código **limpo e legível**

### Frontend
- Use **Bootstrap 5** para estilização
- Mantenha **CSS e JS separados**
- Siga o **design glassmorphism** existente
- Garanta **responsividade** (mobile-first)

### Git
- Commits descritivos no **português** ou **inglês**
- Branches com nomes descritivos
- Pull Requests com descrição clara

## ✅ Checklist antes de enviar um PR

- [ ] Código compila sem erros
- [ ] Testei localmente
- [ ] Adicionei comentários quando necessário
- [ ] Atualizei a documentação (README.md)
- [ ] Meu código segue os padrões do projeto

## 📄 Code of Conduct

Seja respeitoso e profissional. Ofereça feedback construtivo.
