# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [1.0.0] - 2026-07-31

### 🎉 Lançamento Inicial

#### Adicionado
- Sistema completo de monitoramento climático
- Integração com API do OpenWeather
- Dashboard com clima atual
- Previsão para 7 dias
- Busca por cidade
- Detalhes do dia com gráficos
- Página Sobre
- Páginas de erro personalizadas
- Cache em memória para otimização
- Tratamento de erros e logs
- Rate Limiting para proteção
- Health Checks para monitoramento
- User Secrets para segurança
- Docker e Docker Compose
- CI/CD com GitHub Actions
- Interface responsiva com glassmorphism
- Documentação completa

#### Tecnologias
- ASP.NET Core 10.0
- C# 12
- Bootstrap 5
- Chart.js
- OpenWeather API
